Capture the current X11 screen or one application window on Linux/WSL. Use action list to discover displays and window ids/app names/titles before selecting an ambiguous window. Use target window with a window id, exact app name, or case-insensitive title substring. Minimized windows are temporarily restored and re-minimized by default. Captures are saved as PNG outside the project and shown to the user. If there is no display, no xwininfo/import/xwd backend, or a blank protected capture, report the stable error instead of retrying blindly.
